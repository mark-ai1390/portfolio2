## Начало сессии

1. `pwd`; используйте существующий checkout. Облачная задача уже изолирована — не создавайте worktree без запроса пользователя.
2. Прочитайте `claude-progress.md`, `feature_list.json` и план; проверьте `git status --short` и `git log --oneline -5`.
3. Выполните `./init.sh`: установка по lockfile, сборка с typecheck, Playwright smoke и проверки доступного поведения.
4. Выберите один незавершённый этап с наивысшим приоритетом. Сначала исправьте сломанную базовую верификацию. Если этап заблокирован материалами, документируйте причину и делайте независимую работу.

## Команды

- `npm ci`: установка по package-lock.json; Node.js >=22.12.0.
- `npm run dev`: сервер разработки. `RUN_START_COMMAND=1 ./init.sh`: полная проверка и запуск, PORT по умолчанию 5173.
- `npm run build`: TypeScript и production-сборка; `npm run preview`: проверка dist.
- `npm test`: Playwright; `npm run test:smoke`: базовый запуск.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test`: системный браузер в облаке. Без него: `npx playwright install chromium`.

## Правила реализации

- Работайте по этапам feature_list.json; passing требует запущенной проверки и доказательства. Структурная проверка не доказывает визуальное соответствие Figma.
- Сверяйте главную и normal/hover по оригиналам; не перерисовывайте логотипы, мокапы или портрет и не выдавайте временные материалы за готовые. Скачивайте разрешённые экспорты в public/assets, не оставляйте временные URL Figma.
- Тексты, ссылки и порядок разделов храните отдельно от компонентов. Не выдумывайте метрики, биографию или результаты проектов.
- Главная: фон #121213, desktop-колонки 360/64/856, карточки с gap 24, radius 32, padding 20; изображения 816×489, radius 14. Sticky отключайте при недостаточной высоте/ширине окна.
- Карточка становится одной ссылкой на готовый кейс; никаких пустых ссылок и работающих только на hover действий. Не создавайте фиктивные страницы кейсов, чтобы скрыть незавершённость.
- Проверяйте клавиатуру, заметный focus, reduced motion, touch, прямые URL, возврат и ширины 1440/1280/1024/768/390/375 плюс короткое окно ноутбука.
- Кнопку резюме подключайте после получения файла/URL; видео портрета — muted, playsinline, poster и статичный fallback. Отсутствующие материалы фиксируйте как блокеры.
- Сохраняйте пользовательские изменения и секреты вне Git. Не меняйте критерии проверки ради passing.
